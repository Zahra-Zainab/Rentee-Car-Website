# Rentee-Car-Website

## Project Description
Rentee-Car-Website is a fully responsive, visually appealing website built using **HTML** and **External CSS**. It provides a seamless user experience for users looking to explore and rent cars online. The website includes various animations for smoother interactions and a visually stunning layout. Favicon icons are also added to enhance branding and usability.

## Features
- **Responsive Design**: Fully responsive across desktop, tablet, and mobile devices.
- **Animations**: Smooth animations implemented using CSS to improve user experience.
- **Favicon Icons**: Custom favicons added for a polished and branded look.
- **Car Listings**: Users can browse available cars with detailed information.
- **Contact Form**: A contact form for users to get in touch with the company.

## Technologies Used
- **HTML**: Structure and content of the website.
- **CSS**: External CSS for styling and layout, including custom animations.
- **CSS Animations**: To provide dynamic user interactions and smooth transitions.
- **Favicon Icons**: Added for browser tab branding.
